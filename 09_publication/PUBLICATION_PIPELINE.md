# Publication Pipeline

1. Freeze the claim set supported by experiments.
2. Build the related-work evidence map.
3. Draft the manuscript from verified citations and actual results.
4. Run a harsh internal review.
5. Choose venues only after checking scope, indexing, deadlines, formatting, fees, ethics, and submission rules from official sources.
6. Prepare figures, tables, supplementary files, code, environment information, and reproducibility notes.
7. Run a final claim-to-evidence audit.
8. Submit.
9. Preserve submission version, date, venue, manuscript ID if available, and all reviewer correspondence.
10. For revisions or rebuttals, log every requested change and the evidence used to answer it.

Never guarantee acceptance or a quartile outcome.
