# Required Artifacts

For long research tasks, create durable artifacts rather than leaving the result only in chat.

Core artifacts include a domain landscape, dataset table, bibliography, paper notes, literature matrix, gap table, topic decision table, architecture specification, experiment matrix, experiment log, error analysis, figures and tables register, decision log, manuscript, reviewer checklist, publication tracker, and current-state note.

Use Obsidian-compatible Markdown for durable knowledge. Use spreadsheets for large matrices or experiment trackers when scale makes Markdown awkward. Use PDF reports only when a fixed-layout deliverable is useful.

## Graph-native artifacts
For projects where reasoning traceability matters, maintain:
1. constraint nodes,
2. decision nodes,
3. source or evidence nodes,
4. dataset nodes,
5. candidate-topic nodes,
6. rejection or downgrade nodes,
7. a knowledge-graph map linking the active reasoning chain.
